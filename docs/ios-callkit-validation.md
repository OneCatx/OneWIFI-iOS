# iOS CallKit 验收与运行边界

## 本次功能边界

原生统一处理网关信令、CallKit 和 PCM；Flutter 负责登录配置、按钮意图与状态展示。系统接听/挂断与 App 内操作使用同一个通话状态。未接 APNs/PushKit，App 挂起或退出后不能保证新来电可达；后台音频只用于真实通话，不用于待机保活。

网关必须具备 `/api/calls/events`、呼叫控制、DTMF、媒体元数据及 PCM WebSocket 接口。详情见 [HTTP API](http-api.md)。本仓库更新不会部署网关，也不代表 Android/WEB 任务的服务端代码已经在线。

## 监听过期截图的恢复与诊断验收

登录“在线”只表示登录会话可用，不证明 `/api/calls/events` 已取得合法快照。截图中的地址未显示协议，不能据此认定 HTTP、证书失败或网关版本；本地 WEB 源码也不能证明已部署的网关版本。

本轮恢复补丁的验收要求如下，必须在更新后的安装包验证，不能以源码修改代替真机结果：

- 首份有效快照前仍禁用拨出；连接中显示同步中，网络断开/过期显示自动重试，终止型失败显示可操作的原因，不再笼统提示等待。
- 临时 HTTP 408/429/5xx（不含表示接口不支持的 501）走原有封顶退避；401/403、204/404/501、错误 MIME/快照和 TLS/ATS 失败不自动反复重试。
- 系统通话区域的重连和原有“刷新”通过同一个 `refreshEvents` 命令，只重启 SSE；不重新登录、不重建 CallKit 会话、不重拨、不重连媒体。连接中/已连接重复刷新幂等。
- 有通话时刷新须保留 UUID、所有权、媒体及原有离线 20 秒安全期限；反复点击不能延长期限。后台、旧代次、已注销和 `call_history_limit` 安全停流不能借刷新复活。
- `eventError` 是独立、可选的安全诊断字段，不覆盖本机通话错误或远端结束待确认提示。只展示固定分类，不显示 URL、token、电话号码、响应正文或任意原始错误。
- 合法空快照应显示当前无设备，而不是仍在等同步；错误数据不能作为空快照接受。

如果新包仍无法同步，只需提供系统通话区域的新状态/错误码、安装构建标识、登录的 HTTP/HTTPS 选择及网关版本。不要发送 token、P12、证书私钥或完整 SSE 呼叫内容。取得这些证据前，截图背后的唯一运行原因仍未确定。

本轮截图恢复补丁的 Flutter 回归：`flutter test --no-pub --reporter failures-only` → 895 项通过；`flutter analyze --no-pub` → No issues found；涉及 Dart 文件定向格式检查 0 changed；`git diff --check` → exit 0（仅提示既有 CRLF/LF 转换）。原生编译、XCTest 和真机验证在当前 Windows 环境均为 **NOT RUN**，不能把这些 Flutter 结果写成 CallKit 已在设备生效。

## iPhone 与测试网关验收

仅在获得授权的测试号码/设备上执行真实呼叫；不要使用紧急号码。每次失败先确认远端呼叫已结束，再开展下一项。

- 冷登录后不进入通话页也能发现所有设备来电；无麦克风权限时不录音，授权后状态可恢复。
- App 和系统入口各测试拨号、接听、拒接、挂断；快速重复操作只产生一次相应网关操作。
- 系统挂断时待确认提示为中性，网关确认后清除；拨号未发出即取消不显示远端待确认，已发请求但结果未知不能误报远端已结束。旧结束/补偿响应不能修改后一通电话的提示。
- 振铃不开麦；early media 只播放下行；CallKit 激活后且明确属于本机的 active 通话才上传麦克风。
- 双向声音、静音/取消静音、听筒/扬声器、蓝牙连接与移除；静音后无排队旧音频泄漏。
- 已接通通话切页、切卡、退后台、锁屏至少 10 分钟，声音连续；返回后本机通话入口与状态一致。
- 网关协商支持时发送真实 DTMF；未协商/远端失败时不显示成功，不重放按键。
- 同一通话连续两次按键或系统事务返回相同错误码，中间有新的本地输入提示时，后一次真实失败仍应正确显示；不把旧状态重发当新失败覆盖用户较新的提示。
- 另一客户端先接听、远端先取消、第二来电、媒体已占用：不冒领、不争抢媒体、不挂断不属于本机的通话。
- 系统电话/音频中断、系统 reset、路由变化：立即停不该运行的音频，只有系统重新激活后恢复。
- 断网/慢网、失效 token、旧后端、畸形 SSE/PCM、满缓冲、未知 POST 结果：明确失败，不重发拨号或无限重连。
- 登出、换网关、换证书信任、旧请求迟到：旧音频和旧代次失效，新 token 不发送到旧 origin。
- TLS：系统有效证书、正确自签 pin、错误 pin、过期/尚未生效证书、主机不匹配、重定向。pin 失败不能回退系统 CA；公开 HTTP 被拒绝。
- 空闲退后台后停止监听，不承诺后台新来电；回前台按新鲜快照恢复，不重放已结束来电。

## 回滚

先停止并确认本机呼叫终态，再成组回退原生入口、Flutter iOS 接入及工程配置。没有数据库迁移。不要在通话中自动切回旧媒体链路；代码回滚不能撤销已经发出的外部呼叫。既有签名材料和用户 `artifacts/` 不属于本次回滚范围。
