# 本机连接信任与更新通道

HTTPS 不再接受任意证书。私有 APK 仓更新与 OneIMS Ultra / OneTools 同一做法：打包时注入只读令牌，设置页不用再贴凭据。

## 自签证书

使用系统信任的有效 HTTPS 证书时，无需额外配置。

自签网关：在登录页填好主机和端口、开启 HTTPS，点击“证书指纹”。从可信的管理界面或管理员处独立核对该服务器证书的 SHA-256 指纹，输入完整 64 位十六进制并保存。不要仅根据一个无法验证的网络连接来信任它。

Mihomo 的自签证书在设置页 Mihomo 表单的 HTTPS 下独立配置。指纹绑定的是协议、主机、端口的组合，不能从网关自动借用到另一台服务器。允许大小写和冒号分隔，内部统一规范化。

保存的是完整叶子证书 DER 的 SHA-256，不是 SHA-1，也不是公钥 SPKI。绑定后 HTTP 和通话 WebSocket 使用相同校验；指纹不符或证书过期时连接失败，不自动更新指纹或降级 HTTP。更换证书后需重新核对。明确点击“清除指纹，恢复系统验证”会恢复系统校验，**不是信任所有证书**。

修改指纹会关闭该地址的旧连接。配置只保存在本机安全存储，退出网关账号不会将其删除。

## 私有 APK 仓库更新

正式包从 `local.properties` 的 `github.update.token` 或环境变量 `GITHUB_UPDATE_TOKEN` 写入 `BuildConfig`，检查更新和下载都带这张只读令牌。令牌不进 git、不进 Dart 源码、不打日志。公开仓库可以留空。

版本检查最多等待 30 秒，退出页面会取消尚未结束的检查。安装仍由 Android 系统确认；进入未知来源授权页后，授权完成需返回重新点击更新。

运行时只把令牌发给固定 GitHub API 仓库资产接口；下载跳转不携带凭据，且拒绝明文降级。

轮换令牌后需要重新打正式包。已经装在用户手机上的旧包不会自动换成新令牌。

## 验证边界

自动化覆盖本地 HTTPS/WSS、权限队列、异步取消和消息/卡身份回归；不等于 OEM 真机通知横幅、后台/锁屏、真实 SIM 或通话音频验收。杀掉进程后停止短信监视仍是现有设计，本次没有新增常驻后台服务。
